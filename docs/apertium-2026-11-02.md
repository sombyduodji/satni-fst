## Can it be trusted?

- **Agreement is not independent.** The sme-nob paper says the dictionary began from Vuosttaš Digisánit, a Giellatekno dictionary. The sme-fin file marks a section as coming from the GT sme-fin dictionary.
- **Norwegian additions look mostly right.** Reading 85 random additions, about 1 in 10 of the 45 with a Finnish word to compare looked wrong or doubtful (*skáhtta* = skatt against *tapporaha*, *ruvdet* = flette against *raudoittaa*). This is one reviewer's reading, not a check by a Sámi speaker.
- **2,038 additions have no Finnish to compare with.** In the sample of 40, nearly all were loanwords with a predictable form (*frapperet* = frappere).
- **Finnish additions are too coarse.** They agree with Vest for only 21 of the 49 words both have, and many of the rest are wrong or very general (*lossut* = kävellä, *gurggistit* = kävellä, *divga* = kello). They are not used.
- **Rare words only.** All 4,581 additions have no `freq` value. That column comes from the Norwegian dictionary, so it does not show how common they are.
- **Provenance is partly unknown.** Later entries were "mostly added manually". Only sme-nob's start is documented.

## Sentence translation

400 random dictionary examples per pair, packaged nightly build, scored against the human translation. Overlap is the share of reference words found in the output, a rough measure.

| | sme-nob | sme-fin |
|---|---:|---:|
| Median word overlap | 58 % | 0 % |
| Output words with errors or unknown | 4.8 % | 42.9 % |
| Sentences with at least one | 28.5 % | 87.0 % |
| Identical to reference | 37 | 6 |

- **sme-nob** gives the gist but also wrong meanings: *máhcahaga* (feedback) became "uten å #dra# tilbake", and pronouns are often misplaced. The published evaluation found 77 % in a multiple choice test, 41 % in fill-in and 75 % in a random-word test.
- **sme-fin** leaks internal tags into the output (`@ADVL-ine→>`) and fails to generate many words. It is unusable as it stands.
- **Examples with no Finnish translation** (2,413 distinct): sme-fin should not be used to fill them. sme-nob output could be read by Norwegian users, but it has errors and would need clear marking.

## Licence

GPL-2 or later can be used under the app's GPL-3. The dictionary, the only file used now, states "or later". Many other pair files have no header.

The app's licence has an extra permission for Google ML Kit. That permission covers only code whose authors granted it, so Apertium's authors have not. Shipping the Apertium engine inside the Android app next to ML Kit needs a closer look first. Data read from a database is a much smaller question.
